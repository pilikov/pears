# Prompt: Altai Sticky Block Reuse

Сделай интерактивный fullscreen-блок по скроллу в стиле “Altai sticky cards”.

## Цель
- Вставить/заменить целевой блок на секцию фиксированной высоты (например, `5000px`).
- Внутри этой секции: pinned-сцена (`sticky`) высотой `100vh`.
- В pinned-сцене:
  - фоновое видео,
  - короткий заголовок (“Алтай”),
  - большой заголовок (“Место силы и вдохновения”) с reveal-анимацией (как в `primland-reveal-suite`),
  - карточка справа снизу (картинка + текст), смена по скроллу.
- После конца диапазона fixed-height блока секция должна отпускаться, и страница скроллится дальше.

## Критично
1. Не ломай существующую структуру брейкпоинтов.
2. Если у экспортной страницы фиксированная высота breakpoint-контейнера, пересчитай ее после замены блока (`style.height = scrollHeight`), иначе низ сайта обрежется.
3. Не использовать хрупкий поиск по одному авто-классу. Лучше: точка входа через `video[src*="river.mp4"]` + `closest(...)`.
4. Не заменяй фоновые медиа других блоков.
5. Для карточек использовать hold-модель:
   - `exactRaw = progress * (cards.length - 1)`
   - `step = floor(exactRaw)`
   - `local = exactRaw - step`
   - `transitionProgress = clamp((local - CARD_HOLD_PORTION)/(1-CARD_HOLD_PORTION), 0, 1)`
   - переключение `nextIndex` ближе к концу transition (`>= 0.75`).

## Параметры (дефолт)
- `BLOCK_HEIGHT_PX = 5000`
- `CARD_HOLD_PORTION = 0.82`
- `cardWidth = 460`
- `cardRight = 156`
- `cardRadius = 16`
- `cardPadding = 32`
- `cardText = 24/28`

## Визуальные требования
- “Алтай” слева, `text-align: left`, стиль smallcaps lead.
- Карточка: без border, радиус 16, паддинги 32, ширина ровно 460px (desktop).
- Учитывать `prefers-reduced-motion`.

## Что сдать
1. Файл CSS блока.
2. Файл JS инициализации блока.
3. Где именно заменяется целевой блок в DOM.
4. Короткая валидация:
   - pin держится в рамках блока,
   - карточки меняются по шагам,
   - после блока страница продолжается,
   - низ сайта не обрезан.
